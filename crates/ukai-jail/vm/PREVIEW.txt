Ukai VM 0.1.0-preview.1 for Apple Silicon / macOS 27+

This developer preview runs Linux ARM64 commands in an offline disposable VM.
It does not run macOS binaries, Xcode, or native Apple SDKs. The native macOS
Jail backend remains unavailable pending a proven process-lifetime boundary.

INSTALL
Open the signed, notarized DMG, then run in Terminal:
  bash "/Volumes/Ukai VM Preview/install.sh"
  export PATH="$HOME/.local/bin:$PATH"
  ukai-vm doctor

Python, Swift, Rust, Homebrew, sudo, and Endpoint Security approval are not
required. The installer checks pinned SHA-256 hashes and expands a private
6 GiB sparse image. Allow 8 GiB free space and use an APFS installation/output
volume. Each running attempt needs 2 GiB RAM and two virtual CPUs.

RUN
  mkdir -p /tmp/ukai-input
  printf 'hello\n' > /tmp/ukai-input/input.txt
  ukai-vm run --workspace /tmp/ukai-input --out /tmp/ukai-result \
    --profile build --wall 30 -- \
    /bin/sh -c 'cat input.txt; printf "Linux output\n" > result.txt'

Use a new --out directory for every attempt. Inputs are copied; outputs are
returned under <out>/workspace and must be adopted manually. The original
workspace is never shared with or modified by the VM. Both profiles can write
the disposable workspace copy: tool includes that baseline access; build adds
an explicit workspace grant. Protected system paths remain read-only.
No network adapter, directory shares, host credentials, interactive stdin,
background/resumable VM, or agent/provider integration is exposed.

Limits: 5,000 input/output files, 512 KiB per file, 32 MiB total; no symlinks,
devices or FIFOs. Empty directories are not preserved. .git, target,
node_modules, .venv, __pycache__ and .DS_Store are excluded at every level.
Guest commands have 512 MiB memory, no swap, 64 processes, and a wall limit
of 1-300 seconds. The guest includes Python and a shell, not a full build SDK.

A completed attempt requires a verified Linux Jail receipt and acknowledged
VM stop. Failure or incomplete evidence returns 125. A crashed launcher may
leave a disposable disk in its attempt directory; never boot or reuse it.
Delete that attempt directory when its evidence is no longer needed.

Lifetime coverage includes individual launcher, VM client and custodian loss
or suspension, and suspension of each pair. If all three host controllers are
simultaneously suspended, host VM-resource teardown is not guaranteed until
one resumes; the independent guest lease still terminates its workload.
Host sleep, kernel failure and arbitrary guest compromise are not qualified.
There is no claim of native macOS process-tree containment or production
readiness. Read the accompanying source README for the measured fault model.

UNINSTALL
Remove ~/.local/bin/ukai-vm and ~/.local/share/ukai-vm/0.1.0-preview.1.
Attempt output directories remain yours to retain or delete.

LICENSES AND PROVENANCE
Ukai and bundled runtime licenses are in payload/licenses. The guest
contains Ubuntu package copyright notices in /usr/share/doc and package
versions in /usr/local/share/ukai-vm/packages.txt. Its dated upstream image and
Linux Jail archive URLs/hashes are recorded in payload/image/image.json.
The setup uses Ubuntu package repositories without a snapshot pin; the final
distributed disk is pinned by SHA-256. The source for this preview is included
as preview-source.tar.gz. This candidate has not been published publicly.
