# Microsoft MXC (Microsoft eXecution Container) — v1.0.0 Feature Summary

**Repo:** https://github.com/microsoft/mxc · Rust · MIT · **Version 1.0.0** (Rust workspace `version = "1.0.0"` in [src/Cargo.toml](https://raw.githubusercontent.com/microsoft/mxc/main/src/Cargo.toml); Node SDK `@microsoft/mxc-sdk` `1.0.0` in [sdk/node/package.json](https://raw.githubusercontent.com/microsoft/mxc/main/sdk/node/package.json); stable config schema `1.0.0` — "first stable contract", [docs/schema.md](https://raw.githubusercontent.com/microsoft/mxc/main/docs/schema.md)). .NET `Microsoft.Mxc.Sdk` NuGet version not directly verified on nuget.org (its [CHANGELOG.md](https://raw.githubusercontent.com/microsoft/mxc/main/sdk/dotnet/CHANGELOG.md) tops out at `0.9.0` + Unreleased) — otherwise UNKNOWN.

MXC is a **sandboxed code-execution system for running untrusted code (model output, plugins, tools)** — an SDK that builds into your app, not a service ([README](https://github.com/microsoft/mxc/blob/main/README.md)). **License: MIT** ([LICENSE.md](https://raw.githubusercontent.com/microsoft/mxc/main/LICENSE.md)). GitHub Copilot's GA local sandboxing (Oct 2026) is powered by MXC ([GitHub changelog](https://github.blog/changelog/2026-10-07-local-sandboxing-for-github-copilot-now-generally-available/)).

## 1. Platform support & containment backends

From the [README platform table](https://github.com/microsoft/mxc/blob/main/README.md) (\* = experimental):

| Runtime platform | Default backend | Other backends |
|---|---|---|
| Windows 11 x64 / ARM64 | `processcontainer` | `windows_sandbox`\*, `wslc`, `microvm`\*, `hyperlight`\*, `isolation_session` |
| Linux x64 / ARM64 | `bubblewrap` | `lxc`, `microvm`, `hyperlight` |
| macOS ARM64 / x64 | `seatbelt` | — |

Abstract intents: `"process"` → processcontainer/bubblewrap/seatbelt per OS; `"vm"` → windows_sandbox; `"microvm"` → Nanvix (experimental) ([schema.md §Containment Backends](https://raw.githubusercontent.com/microsoft/mxc/main/docs/schema.md)).

Backend notes & sources:
- **ProcessContainer** (Windows, default): resolves AppContainer (legacy) or BaseContainer/PSEC at runtime; Windows 11 build floors (e.g. 24H2 ≥26100.9278 process / ≥26100.9550 session; 25H2/26H2/26H1 rows) in [os-version-support.md](https://raw.githubusercontent.com/microsoft/mxc/main/docs/backends/process-container/os-version-support.md).
- **Windows Sandbox** (experimental, `--experimental`): disposable VM per create-and-run; daemon-backed lifecycle; one VM per logon session ([windows-sandbox.md](https://raw.githubusercontent.com/microsoft/mxc/main/docs/backends/windows-sandbox/windows-sandbox.md)).
- **WSLC** (stable, v0.9+): Linux containers via WSL Container SDK; Windows 10 1903+/2004+ ARM64, WSL 2.9.9+, `wslcsdk.dll`; admin registry allowlist `HKLM\SOFTWARE\Policies\Mxc\WslcAllowedImageRegistries` ([wsl-container-getting-started.md](https://raw.githubusercontent.com/microsoft/mxc/main/docs/backends/wslc/wsl-container-getting-started.md)).
- **Bubblewrap** (Linux default, stable): unprivileged user-namespace sandbox; bwrap ≥0.5.0; slirp4netns+iptables for network-enabled modes ([bubblewrap-backend.md](https://raw.githubusercontent.com/microsoft/mxc/main/docs/backends/bwrap/bubblewrap-backend.md)).
- **LXC**: native LXC ≥5.0; root or unprivileged; must be requested explicitly ([lxc-backend.md](https://raw.githubusercontent.com/microsoft/mxc/main/docs/backends/lxc/lxc-backend.md)).
- **Seatbelt** (macOS): kernel sandbox via generated profile + `sandbox_init()`; requires **macOS 15+**; no root/daemon/install ([seatbelt-backend.md](https://raw.githubusercontent.com/microsoft/mxc/main/docs/backends/seatbelt/seatbelt-backend.md)).
- **MicroVM (Nanvix)** (experimental, `--experimental`, `--with-microvm` build): WHP on Windows / KVM on Linux; ~100 ms cold start, ~100 MB RAM, 256 MB guest RAM, FAT32 <4 GB files ([nanvix.md](https://raw.githubusercontent.com/microsoft/mxc/main/docs/backends/nanvix/nanvix.md)).
- **Hyperlight** (experimental, `--experimental`, schema `1.1.0-alpha`, x86_64 only, KVM/WHP): Unikraft unikernel micro-VMs with warm snapshots; guest runtimes `agent` (default; CPython 3.12 + numpy/pandas/scipy/scikit-learn/matplotlib/Pillow…), `python`, `python-shell`, `node` (Node 22), `bash`, `dotnet-jit` ([hyperlight-backend.md](https://raw.githubusercontent.com/microsoft/mxc/main/docs/backends/hyperlight/hyperlight-backend.md)).
- **IsolationSession** (Windows): per-execution isolated Windows agent-user account in an OS-managed session via WinRT `Windows.AI.IsolationSession.Preview` (private WinMD, internal OS feature flag); not marked experimental in the README table and "does not require runtime experimental authorization" ([schema.md](https://raw.githubusercontent.com/microsoft/mxc/main/docs/schema.md), [oneshot.md](https://raw.githubusercontent.com/microsoft/mxc/main/docs/development/architecture/backends/isolation-session/oneshot.md)).

## 2. Configuration model

- **JSON container-creation request** ("MXC request JSON"): versioned schema — stable [`schemas/stable/mxc-config.schema.1.0.0.json`](https://github.com/microsoft/mxc/blob/main/schemas/stable/mxc-config.schema.1.0.0.json), dev `1.1.0-alpha`, minimum `0.9.0-alpha`; exact `version` string required, no fallback. Top-level sections: `containment`, `lifecycle` (`destroyOnExit`, `preservePolicy`), `process` (`commandLine` required, `cwd`, `env`, `inheritDefaultEnv`, `timeout`), `filesystem`, `network`, `ui`, `fallback.allowDaclMutation`, backend blocks (`processContainer`, `lxc`, `seatbelt`, `wslc`, `hyperlight`), `telemetry` ([schema.md](https://raw.githubusercontent.com/microsoft/mxc/main/docs/schema.md)).
- **Executor binaries**: `wxc-exec.exe` (Windows), `lxc-exec` (Linux; serves LXC/Bubblewrap/Hyperlight), `mxc-exec-mac` (macOS); accept JSON configs, `--debug`, `--audit`, `--operation`/`--container-id`, `--config-base64`; plus `mxc-diagnostic-console.exe` and daemons `wxc-windows-sandbox-daemon/guest`, `wxc-wslc-daemon` ([README](https://github.com/microsoft/mxc/blob/main/README.md), [seatbelt-backend.md](https://raw.githubusercontent.com/microsoft/mxc/main/docs/backends/seatbelt/seatbelt-backend.md), [windows-sandbox.md](https://raw.githubusercontent.com/microsoft/mxc/main/docs/backends/windows-sandbox/windows-sandbox.md), [src/Cargo.toml](https://raw.githubusercontent.com/microsoft/mxc/main/src/Cargo.toml)). A C-callable `mxc_ffi` library uses the same contracts; no separate FFI format.
- **SDKs**: **Rust** `mxc-sdk` (crates.io/crates/mxc-sdk; synchronous; builds engine + backends in-process), **.NET** `Microsoft.Mxc.Sdk` (NuGet; public API `Microsoft.Mxc.Sdk.V1`; sync+async), **Node** `@microsoft/mxc-sdk` (npm; `…/v1` export; Node ≥24; ships native runtime assets) ([README](https://github.com/microsoft/mxc/blob/main/README.md), [api-reference README](https://raw.githubusercontent.com/microsoft/mxc/blob/main/docs/api-reference/README.md), [dotnet README](https://raw.githubusercontent.com/microsoft/mxc/main/sdk/dotnet/README.md)). No first-party Python SDK. I/O models: captured `run`, live-pipe `spawn`, PTY `spawnWithPty` ([glossary.md](https://raw.githubusercontent.com/microsoft/mxc/main/docs/glossary.md)).

## 3. Filesystem policy

- Cross-backend: `filesystem.readwritePaths` / `readonlyPaths` / `deniedPaths` (string[], default `[]`) ([schema.md](https://raw.githubusercontent.com/microsoft/mxc/main/docs/schema.md)). ProcessContainer-only `processContainer.filesystem.enumeratePaths` (enumerate without read; needs PSEC 1.1 `fs_enumerate`; incompatible with `leastPrivilege`).
- **Windows**: BaseContainer grants cascade to descendants except volume roots (`C:\` does not cascade); `deniedPaths` natively via PSEC `PSE_SUPPORT_FS_DENY` (Tier 1) or host DENY ACEs (Tier 2/3, gated by `allowDaclMutation`, restored on exit) ([schema.md](https://raw.githubusercontent.com/microsoft/mxc/main/docs/schema.md)).
- **Seatbelt**: translated to `(allow/deny file-read*/file-write* …)` subpath rules; `deniedPaths` emitted last (wins); `~` expansion, symlink-root resolution, always-on read-only baseline for system paths ([seatbelt-backend.md](https://raw.githubusercontent.com/microsoft/mxc/main/docs/backends/seatbelt/seatbelt-backend.md)).
- **Bubblewrap**: deny-by-default RO baseline of system dirs; `readwritePaths`→`--bind`, `readonlyPaths`→`--ro-bind`, `deniedPaths`→empty tmpfs (dir) or `/dev/null` bind (file) ([bubblewrap-backend.md](https://raw.githubusercontent.com/microsoft/mxc/main/docs/backends/bwrap/bubblewrap-backend.md)).
- **LXC**: bind mounts with ro/rw/denied enforcement ([lxc-backend.md](https://raw.githubusercontent.com/microsoft/mxc/main/docs/backends/lxc/lxc-backend.md)). **WSLC**: image-based; policy mapped into the container. **Windows Sandbox**: maps existing directories ro/rw at same path; `deniedPaths` accepted only outside shares ([windows-sandbox.md](https://raw.githubusercontent.com/microsoft/mxc/main/docs/backends/windows-sandbox/windows-sandbox.md)). **Nanvix**: paths copied into per-run staging snapshot, copy-back after exit; `deniedPaths` **rejected** ([nanvix.md](https://raw.githubusercontent.com/microsoft/mxc/main/docs/backends/nanvix/nanvix.md)). **Hyperlight**: each path mounted at `/host/<basename>` ro/rw; `deniedPaths` checked at preflight ([hyperlight-backend.md](https://raw.githubusercontent.com/microsoft/mxc/main/docs/backends/hyperlight/hyperlight-backend.md)). **IsolationSession**: filesystem policy rejected outright (no host-folder-sharing primitive) ([oneshot.md](https://raw.githubusercontent.com/microsoft/mxc/main/docs/development/architecture/backends/isolation-session/oneshot.md)).

## 4. Network policy

Directional model (schema ≥0.9): `network.egress{default,allow[],deny[]}` with rules `to:[{cidr}]` + `ports:[{protocol,port}]`, and `network.ingress{default,hostLoopback}`. **All default to `deny` when omitted**; `hostLoopback` resolves independently; direct egress rules and `runtimeConfig.networkProxy` are mutually exclusive ([schema.md §Directional networking](https://raw.githubusercontent.com/microsoft/mxc/main/docs/schema.md)).

- **Hostnames: NOT supported anywhere in the current contract.** ProcessContainer GA explicitly excludes "durable DNS-name rules" ([networking.md](https://raw.githubusercontent.com/microsoft/mxc/main/docs/backends/process-container/networking.md)); Bubblewrap rejects DNS names at validation (IP literals/CIDR only) ([bubblewrap-backend.md](https://raw.githubusercontent.com/microsoft/mxc/main/docs/backends/bwrap/bubblewrap-backend.md)); Seatbelt rejects hostname rules (no primitive; `(remote …)` accepts only `*`/`localhost`) ([seatbelt-backend.md](https://raw.githubusercontent.com/microsoft/mxc/main/docs/backends/seatbelt/seatbelt-backend.md)). Legacy `allowedHosts`/`blockedHosts`/`network.proxy` fields are retired and rejected.
- **Proxy support**: `runtimeConfig.networkProxy` (loopback HTTP/S URL, caller-managed proxy owns destination filtering). ProcessContainer: per-container WinHTTP proxy + WFP endpoint scoping + `processContainer.network.allowedProxyPeer` identity pinning (package family / AppContainer profile; identity-less mode needs `hostLoopback: allow`, dev/test only) ([networking.md](https://raw.githubusercontent.com/microsoft/mxc/main/docs/backends/process-container/networking.md)). Bubblewrap: proxy-only egress via slirp4netns gateway. Seatbelt: egress confined to proxy endpoint (kernel-enforced), proxy use cooperative. LXC, Windows Sandbox, Nanvix, Hyperlight, IsolationSession: proxy rejected ([lxc-backend.md](https://raw.githubusercontent.com/microsoft/mxc/main/docs/backends/lxc/lxc-backend.md), [windows-sandbox.md](https://raw.githubusercontent.com/microsoft/mxc/main/docs/backends/windows-sandbox/windows-sandbox.md), [nanvix.md](https://raw.githubusercontent.com/microsoft/mxc/main/docs/backends/nanvix/nanvix.md), [hyperlight-backend.md](https://raw.githubusercontent.com/microsoft/mxc/main/docs/backends/hyperlight/hyperlight-backend.md), [schema.md](https://raw.githubusercontent.com/microsoft/mxc/main/docs/schema.md)).
- Per-backend enforcement: ProcessContainer = WFP per-container egress filters (IPv4+IPv6, explicit deny wins) + AppContainer capabilities matrix; Bubblewrap = in-namespace iptables (CAP_NET_ADMIN supervisor, unprivileged, `except` via CIDR subtraction, protocols tcp/udp/icmp/any bounded by slirp4netns transport); LXC = iptables in container netns (port 53 treated like any destination; no implicit DNS exemption); Seatbelt = on/off egress + loopback exception only; Windows Sandbox = guest-firewall block-only (any network policy section supplied → rejected); Nanvix = all-deny (no sockets) or all-allow unrestricted (mixed rejected); Hyperlight = network rejected (guest offline); IsolationSession = cannot restrict — all three directional values must be explicit `allow` (sources as cited above).

## 5. UI policy

`ui` section, default-deny: `disable` (default `true`), `clipboard` (`none|read|write|all`, default `none`), `injection` (default `false`). Enforced by **Windows ProcessContainer** (job-object UI restrictions + Win32k `DisallowWin32kSystemCalls` mitigation) and **macOS Seatbelt** (generated profile). ProcessContainer-only sub-fields: `isolation`, `desktopSystemControl`, `systemSettings`, `ime`. Other backends do not implement it; **IsolationSession and WSLC refuse any supplied `ui`** and apply no restriction when omitted ([schema.md §UI Policy](https://raw.githubusercontent.com/microsoft/mxc/main/docs/schema.md), [UIPolicy_Schema.md](https://raw.githubusercontent.com/microsoft/mxc/main/docs/backends/process-container/UIPolicy_Schema.md)). Seatbelt-specific: `seatbelt.guiAccess`, `nestedPty`, `keychainAccess`, `extraMachLookups`, `profileOverride` ([schema.md](https://raw.githubusercontent.com/microsoft/mxc/main/docs/schema.md)).

## 6. Resource limits

- **Timeout**: `process.timeout` (ms; 0 = none) in JSON; `TimeoutMs` in SDKs; enforced across backends (e.g. Hyperlight interrupts overruns; IsolationSession forwards to OS per-process timeout) ([schema.md](https://raw.githubusercontent.com/microsoft/mxc/main/docs/schema.md), [hyperlight-backend.md](https://raw.githubusercontent.com/microsoft/mxc/main/docs/backends/hyperlight/hyperlight-backend.md), [oneshot.md](https://raw.githubusercontent.com/microsoft/mxc/main/docs/development/architecture/backends/isolation-session/oneshot.md)).
- **WSLC-only sizing**: `wslc.cpuCount`, `memoryMb`, `gpu`, `storagePath`, `portMappings` (TCP only; UDP hard-rejected) — create-and-run only ([schema.md](https://raw.githubusercontent.com/microsoft/mxc/main/docs/schema.md)).
- **No cross-backend CPU/memory limits** in the stable schema (a `resources` section is cited only as a hypothetical bump example); Nanvix fixed 256 MB guest RAM; Windows Sandbox create-and-run stdin capped at 64 MiB ([schema.md](https://raw.githubusercontent.com/microsoft/mxc/main/docs/schema.md), [nanvix.md](https://raw.githubusercontent.com/microsoft/mxc/main/docs/backends/nanvix/nanvix.md), [windows-sandbox.md](https://raw.githubusercontent.com/microsoft/mxc/main/docs/backends/windows-sandbox/windows-sandbox.md)).

## 7. Lifecycle operations

Two models ([container-lifecycle.md](https://raw.githubusercontent.com/microsoft/mxc/main/docs/container-lifecycle.md), [glossary.md](https://raw.githubusercontent.com/microsoft/mxc/main/docs/glossary.md)):
- **Create-and-run (transient)**: `run`/`spawn` with `ContainerRequest`.
- **Persistent lifecycle**: `provision` → opaque `ContainerId` → `start` → `exec` (`ExecutionRequest`) → `stop` → `deprovision`; state table Not provisioned/Provisioned/Running; typed SDK ops (`container::provision_container`, `MxcLifecycle.*`, `provisionContainer`…); JSON carries `phase`+`sandboxId` (executor: `--operation`/`--container-id`). **Lifecycle-capable backends: `isolation_session`, `windows_sandbox`, `wslc` (all Windows-only)** ([schema.md](https://raw.githubusercontent.com/microsoft/mxc/main/docs/schema.md)). Neither persistent nor transient promises survival across host reboots; explicit validation APIs (`Validate*`) do native dry-runs. `lifecycle.destroyOnExit`/`preservePolicy` flags govern teardown/policy retention.

## 8. Diagnostics

([README](https://github.com/microsoft/mxc/blob/main/README.md), [diagnostics.md](https://raw.githubusercontent.com/microsoft/mxc/main/docs/development/guides/diagnostics.md), [logging-access-denied.md](https://raw.githubusercontent.com/microsoft/mxc/main/docs/logging-access-denied.md))
- **Debug console mode**: `wxc-exec --debug config.json` (diagnostic output without disturbing workload stdio).
- **Audit mode**: `wxc-exec --audit` — ProcessContainer-only, permissive (turns off deny-by-default; security warning delivered per surface); produces policy-authoring artifacts: `denials.json`, `denials.verbose.json`, `trace.etl`, source-config snapshot, and `Adjusted_*.json` regenerated policy under `%LOCALAPPDATA%\Microsoft\MXC\PLM\logs\…`.
- **Access-denied logging** (`captureDenials`): `mode: "block"` (deny-and-record, safe) vs `mode: "allow"` (audit); `outputPath` (unique run-id stamped; structured JSON pointer on stderr), `retainEtl`. Host selection prefers native PSEC/V2 capture, falls back to guarded WPR.
- **Diagnostic console**: `mxc-diagnostic-console.exe` + `MXC_DIAG_CONSOLE=1` + `MXC_DIAG_PIPE_TOKEN` (authenticated per-session pipe) for live ETW observation; `--log-file` for persisted logs.

## 9. Observation / audit capabilities

- Learning-mode ETW: `learningModeLogging` (deny-and-record) vs `permissiveLearningMode` (allow-and-record); decode of Kernel-General 14/27/28, PLM 14/27/4907, NetworkDecision 1 events; outputs deduped per `(resource, accessType)` with `file|ui|network|capability|other` resource types; bounds: ≤10,000 unique denials, ≤1,000,000 ETW events, ≤4,096 verbose signatures, 256-char property values with SHA-256 digests; verbose artifact redacts file paths (`<REDACTED>`) and usernames ([logging-access-denied.md](https://raw.githubusercontent.com/microsoft/mxc/main/docs/logging-access-denied.md)).
- **Structured local audit records** (JSON lines `{"event":"mxc.…"}`): exit/timeout/kill, enforcement-tier degradation, policy hash, network policy applied, teardown, config rejection (with per-invocation `correlation_id`); local only, never stdout, never uploaded ([diagnostics.md](https://raw.githubusercontent.com/microsoft/mxc/main/docs/development/guides/diagnostics.md)).
- SDK surfaces for warnings/metadata: `Sandbox::warnings()`, `Output::output_metadata`, `ExecutionResult.Warnings`/`OutputMetadata`, FFI `warnings_json_utf8`.

## 10. Agent / LLM integrations

- Positioning: sandbox for "model output, plugins, and tools" ([README](https://github.com/microsoft/mxc/blob/main/README.md)).
- **GitHub Copilot local sandboxing (GA 2026-10-07) is powered by MXC** — Copilot CLI/app/VS Code Agent Host; enterprise-managed policy; applies to local MCP servers and tools ([github.blog](https://github.blog/changelog/2026-10-07-local-sandboxing-for-github-copilot-now-generally-available/)).
- Hyperlight's default guest runtime is **`agent`** — CPython 3.12 preloaded with numpy, pandas, scipy, scikit-learn, matplotlib, Pillow, pydantic, requests, httpx, pip — aimed at agent code execution ([hyperlight-backend.md](https://raw.githubusercontent.com/microsoft/mxc/main/docs/backends/hyperlight/hyperlight-backend.md)).
- Microsoft **agent-governance-toolkit** ships `agt-sandbox` `MxcSandboxProvider` (Python) wrapping MXC executors for agent code sandboxing (docs an older 0.6.0-alpha schema; notes MXC has no tool-allowlist concept and no Python package) ([tutorial](https://github.com/microsoft/agent-governance-toolkit/blob/main/agent-governance-python/agent-sandbox/tutorials/mxc-quickstart/README.md)).
- MXC docs reference a "claw-on-MXC" scenario motivating IsolationSession ([oneshot.md](https://raw.githubusercontent.com/microsoft/mxc/main/docs/development/architecture/backends/isolation-session/oneshot.md)); no first-party OpenClaw/MCP integration exists in the MXC repo itself — UNKNOWN beyond the above.

## 11. Telemetry model

Windows-only and **off by default**: emission requires (per-run `telemetry.enabled` request) AND (MXC-owned user consent) AND (administrative ceiling permits) AND (official Microsoft build with telemetry enabled). Admin policy: `HKLM\SOFTWARE\Policies\Mxc\AllowTelemetry` REG_DWORD (0/1 → blocked, 3 → allowed, absent → unrestricted; unreadable → fail-closed blocked); policy can only subtract, never grant consent; does not read Windows' own `AllowTelemetry`. Local open-source builds route nothing to Microsoft; telemetry is a no-op on non-Windows ([README](https://github.com/microsoft/mxc/blob/main/README.md), [telemetry.md](https://raw.githubusercontent.com/microsoft/mxc/main/docs/telemetry.md)). Authorized telemetry may send the redacted verbose-denials document via `Microsoft.MXC/MXC.VerboseDenials`; the actionable denials file and raw ETL are never sent ([logging-access-denied.md](https://raw.githubusercontent.com/microsoft/mxc/main/docs/logging-access-denied.md)).
