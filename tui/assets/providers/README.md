12×12 alpha masks rasterized from the original Lobe Icons SVGs in
`priv/static/web/providers/` (MIT; license and source attribution there).
The TUI renders the source pixels as half blocks in the selected provider's detail panel,
using the terminal theme. Screen-reader mode omits this decorative image.

Generated with macOS AppKit NSImage at 12×12, alpha threshold >96/255, bit x is column x.
